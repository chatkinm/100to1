# Сто к одному — Pass & Play Web Game

Интерактивная командная веб-игра в формате культового телевизионного шоу **«Сто к одному» (100 to 1 / Family Feud)**. Разработана по аналогии с «Игрой Сани» для игры дружной компанией с одного смартфона, планшета, ноутбука или телевизора без обязательного подключения к интернету.

---

## 🌟 Ключевые возможности

1. **Игра на одном экране (Pass & Play / Host Mode):**
   - 2 команды соперников (с возможностью задать любые названия).
   - Интерактивное **Табло на 6 ответов** с 3D flip-анимацией переворота плашек.
   - Подсчет **Банка раунда** в реальном времени.
   - Механика **Промахов (❌)**: счетчик ошибок (1, 2, 3), всплывающий огромный красный крест и звуковой зуммер.
   - Кнопки для ведущего: начисление банка любой команде, смена хода, открытие всех ответов в конце раунда.

2. **Классические раунды:**
   - **Раунд 1: Простая игра** (множитель очков x1).
   - **Раунд 2: Двойная игра** (множитель очков x2).
   - **Раунд 3: Тройная игра** (множитель очков x3).
   - **Раунд 4: Игра наоборот** (множитель по шкале наименее популярного ответа: 240, 180, 120, 90, 60, 15).
   - **Раунд 5: Большая игра (Суперигра)** — 2 игрока отвечают на 5 блиц-вопросов с таймером на 15 и 20 секунд с целью набрать 200 очков!

3. **Оффлайн и PWA (Progressive Web App):**
   - Работает на 100% без интернета через Service Worker и кэширование.
   - Можно «Установить на экран “Домой”» на смартфонах iOS и Android как нативное приложение.

4. **Автономное звуковое оформление (Web Audio API):**
   - Никаких внешних тяжелых mp3 файлов:
     - Звук открытия ответа (чистый колокольчик / динь).
     - Звук ошибки / промаха (диссонирующий резкий зуммер).
     - Звук победы в раунде (восходящее арпеджио).
     - Тиканье таймера и финальный гонг.
   - Быстрое отключение звука (Mute) в один клик.

5. **Mobile-First + Адаптация под ТВ (Landscape TV View):**
   - На смартфонах — удобный пульт управления.
   - В альбомном режиме и на экранах телевизоров — увеличенное яркое табло с огромными буквами и цифрами, видимое с другого конца комнаты.
   - Кнопка разворачивания на весь экран (Fullscreen).

6. **Встроенный Конструктор игр (Editor):**
   - Создание собственных игр и вопросов с любым количеством раундов.
   - Проверка суммы баллов (до 100).
   - Экспорт пака в файл `.json` (скачать).
   - Импорт пака из файла `.json` (загрузить).
   - Встроенный классический пак с забавными вопросами для вечеринки.

## 📁 Структура проекта

```
100to1/
├── index.html               # Главная страница SPA
├── manifest.json            # PWA манифест
├── sw.js                    # Service Worker (кэширование и оффлайн-работа)
├── README.md                # Описание и инструкции
├── css/
│   └── styles.css           # Стили (нео-ретро табло, 3D flip, мобильный + ТВ режимы)
├── js/
│   ├── app.js               # Главный контроллер и инициализация
│   ├── game.js              # Игровой движок (счет, раунды, банк, промахи, суперигра)
│   ├── editor.js            # Конструктор паков и вопросов
│   ├── db.js                # Работа с локальным хранилищем и импорт/экспорт JSON
│   ├── sound.js             # Звуковой движок на Web Audio API
│   └── sw-register.js       # Регистрация PWA Service Worker
└── assets/
    ├── default_pack.json    # Встроенный готовый пакет вопросов
    └── icons/
        ├── icon-192.png     # Иконка PWA 192x192
        └── icon-512.png     # Иконка PWA 512x512
```

## 🚀 Публикация на GitHub Pages

Чтобы игра открывалась по ссылке в интернете и работала у всех гостей:

1. Создайте репозиторий на GitHub (например, `100to1` или `my_100to1`).
2. В терминале в папке `c:\Users\chatk\100to1` выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: 100 to 1 game"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/100to1.git
   git push -u origin main
   ```
3. Откройте страницу репозитория на GitHub:
   - Перейдите в **Settings** &rarr; **Pages**.
   - В разделе **Branch** выберите `main` и папку `/(root)`.
   - Нажмите **Save**.
4. Через минуту игра будет доступна по адресу:  
   `https://ВАШ_ЛОГИН.github.io/100to1/`
